# Llamadas 360 Implementation Plan

Approved scope: daily CSV import, PostgreSQL history, Netlife/Ecuanet segmentation, dashboard and Excel export. ADMINISTRADOR imports; authenticated non-ASESOR profiles read. Existing Automarcador remains independent.

Architecture: mount analytics under existing /api/llamadas/analitica in both monolithic and split deployments. Pure parsing and aggregation module; transactional repository; bounded uploads and exports; frontend lazy route /llamadas.

- [x] Implement parser tests before parser: exact duplicate exports, overlapping periods, invalid dates/numbers, quoted CSV, phone normalization, absent waiting times, status semantics.
- [x] Add migration for llamadas_cdr and llamadas_cdr_cargas; stable fingerprint includes normalized full call content because source lacks call ID. Identical full rows are duplicates. Changed content is a distinct observation, not an inferred correction. Document limitation.
- [x] Import each batch atomically, validate all files first, ON CONFLICT DO NOTHING, preserve rejected counts and bounded diagnostic samples; enforce file/row limits before acquiring DB connection.
- [x] Add parameterized filtered SQL, aggregation, coverage independent of date filters, paginated detail, and bounded XLSX export with methodology sheet.
- [x] Add backend auth and error boundaries; test unauthenticated/ASESOR/upload restrictions and transaction behavior.
- [x] Build frontend with filters, KPIs, trends, status chart, heatmap, agent/hour analysis, coverage, history, upload summary and export.
- [x] Verify real eight CSV files offline, focused Node tests, frontend build, review changes and limitations. Do not run production migration or push without authorization.

Ruling: use existing checkout and touch only named analytics integrations; preexisting edits remain intact. No production connection is required for offline validation.
Ruling: dates are source-local clock values, shown without timezone conversion. Without provider confirmation, billed seconds are never labelled talk time and ANSWERED is never labelled a verified human contact.
